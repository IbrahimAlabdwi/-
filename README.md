### ⭐ Netlify Drop — لا يحتاج حساب ولا تثبيت شيء!

1. **افتح المتصفح واذهب إلى:**  
   👉 **[https://app.netlify.com/drop](https://app.netlify.com/drop)**

2. **اسحب مجلد `faya` كاملاً وأفلته** في الدائرة الكبيرة في الصفحة

3. **انتظر ثوانٍ** — سيتحول المجلد إلى رابط فوري!

4. اضغط على **"Site settings" → "Change site name"** وسمّه `hikayet-faya`

5. ✅ الرابط النهائي سيكون:  
   **`https://hikayet-faya.netlify.app`**

6. **انسخ الرابط وأرسله لأيمن!** 🎉
